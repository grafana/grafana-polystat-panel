These pages cover how to feed data to Polystat, how to configure it in the panel editor and how to build on it with thresholds, overrides, composites and clickthrough URLs. Option reference lives under **Options**, grouped the same way as the categories in the panel editor.

## Recommended path

Start with [Data formats](./data-formats.md) to understand how Polystat turns query results into polygons. Then read [Thresholds](./thresholds.md), because thresholds decide the color and state of every polygon and both overrides and composites build on them.

- [Apply a different unit, stat or threshold set to specific metrics](./options/overrides.md)
- [Roll several metrics up into one polygon](./options/composites.md)
- [Link a polygon to a drill-down dashboard](./clickthrough-urls.md)
